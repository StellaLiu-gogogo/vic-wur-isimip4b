# isimip3-water-abstraction-review

**Question.** Task D1 of decision D05 (`docs/decisions/D05-non-irrigation-water-use.md`): are the
ISIMIP3a/3b non-irrigation water-abstraction files and the WaterGAP groundwater-fraction tables, as
acquired into `raw/external/`, complete and correct, and what are their properties? In particular:
headers, grid and time axis; fill values versus zeros; negatives, extremes, consumption greater than
withdrawal, withdrawal without population or outside the VIC domain; continuity between files,
ISIMIP3b versus ISIMIP3a, constancy of the fixed-year scenarios, the 2014/2015 and 2021/2022 joins
between histsoc and the SSP series, model spread of the SSP series; global and continental totals
against published estimates. The answer is the data description the user reads before approving the
downscaling producer (task D2).

**Classification.** Analysis; user decision 2026-10-02. Reason: the product is a review and a report
that supports a decision; no workflow stage reads it. The acquisition itself (transfer, manifests) is
`01_acquisition` work; the downscaling of these data is implemented separately in
`workflow/04_forcing/water_use/` (task D2) and does not import this code. The QA summaries are also
recorded under `qc/raw/external/<dataset-id>/<version>/summary.json`, as the contract requires for raw
objects.

**Status.** `open` (report written 2026-10-02; waiting for the user's review and for the answers of
the sector coordinators).

**Inputs** (read-only, paths relative to `$ISIMIP4B_WORKDIR`).

- `raw/external/isimip3-water-abstraction/dkrz-2026-10-02/` (52 files, manifest
  `manifests/inputs/isimip3-water-abstraction.yaml`).
- `raw/external/watergap-groundwater-fractions/snapshot-2026-10-02/` (4 tables, manifest
  `manifests/inputs/watergap-groundwater-fractions.yaml`).
- `raw/ISIMIP4b/InputData/geo_conditions/landseamask/landseamask_water-global.nc` (0.5 degree grid and
  mask), `raw/ISIMIP4b/InputData/geo_conditions/countrymasks/countrymasks-fractional_30arcmin.nc`
  (continents, with `continents.csv`), `raw/ISIMIP4b/InputData/socioeconomic/population/`
  (5 arcmin total population of histsoc, ssp1vlsoc-noadapt, ssp3hsoc-noadapt).
- `parameters/candidates/vic-global-5arcmin-version-a/domain/vic_global_5min_domain_nogl.nc` (active
  VIC cells).
- `published_estimates.csv` (FAO AQUASTAT 2016, Floerke et al. 2013; sources in the file header).
- Documentation read on 2026-10-02 (copies under `workdir/analysis/<task-id>/sources/`): ISIMIP3
  protocol repository `ISI-MIP/isimip-protocol-3` at commit
  `443ef6a75439be83c389007c8b422d5edcd26d42` (`definitions/soc_dataset.yaml`, entry
  `water_abstraction`); the ISIMIP input-data pages "Water abstraction for domestic and industrial
  uses" (details/38) and "Water abstraction (Group III)" (details/189); the DataCite records of
  DOIs 10.48364/ISIMIP.228996, 10.48364/ISIMIP.478291 and 10.48364/ISIMIP.423677. DKRZ holds no
  README for these files.

**Code.**

- `review_water_abstraction.py` — the whole review (tables, figures, QC summaries) in one script.
  It always runs on a compute node: `--submit` renders the Slurm job, keeps its record under
  `workdir/analysis/<task-id>/logs/review_<slurm-job-id>/` and submits it; `--scratch` writes
  everything to `scratch/<task-id>/run/` instead (test runs).
- `continents.csv` — ISO3 code of the ISIMIP4b country masks to continent (UN M49 grouping, Americas
  split into North and South America).
- `published_estimates.csv` — published global and continental reference values.

```bash
conda activate isimip4b
export ISIMIP4B_WORKDIR=/lustre/nobackup/WUR/ESG/liu297/isimip4b/workdir
python analysis/isimip3-water-abstraction-review/review_water_abstraction.py --submit
```

One CPU, about 48 GB memory requested; see the job record for the runtime.

**Outputs.** `workdir/analysis/isimip3-water-abstraction-review/`:

- `report.md` — the data description for the user, written by hand from the tables and figures
  below (not generated by the script).
- `tables/` — `file_headers.csv` (per file: header, grid, time axis, fill, zeros, negatives,
  extremes), `totals_by_region.csv` (every file and year, global, six continents and cells outside
  any country, km3/yr), `constancy_per_file.csv`, `time_checks.csv`, `join_cell_ratios.csv`,
  `join_by_region.csv`, `join_options_global.csv` (raw SSP versus per-cell ratio and offset joins to
  the 2021 value), `ssp_model_spread.csv`, `consumption_fraction.csv`,
  `consumption_fraction_3a_annual.csv`, `withdrawal_without_population.csv`,
  `withdrawal_vs_vic_domain.csv`, `grid_relation.json`, `published_comparison.csv`,
  `groundwater_tables.json`.
- `figures/` — 12 PNG figures (global totals 1601–2100, joins 1990–2100, continents, consumption
  fraction, 2021 maps, join-ratio maps and histograms, model spread, cells needing special handling,
  3b versus 3a, groundwater fractions, year-to-year cell change).
- `sources/` — the documentation listed under Inputs.
- QC summaries: `qc/raw/external/isimip3-water-abstraction/dkrz-2026-10-02/summary.json` and
  `qc/raw/external/watergap-groundwater-fractions/snapshot-2026-10-02/summary.json`.

**Conclusion.** See `workdir/analysis/isimip3-water-abstraction-review/report.md`. The maintained
record of the conclusion will be the D2 design in `docs/decisions/D05-non-irrigation-water-use.md`
once the user has approved it.
